# API Node.js com Express

Projeto desenvolvido para estudos e atividades para portfólio.

## Tecnologias

- JavaScript
- Node.js
- Express

## Objetivo

Praticar o desenvolvimento de APIs REST utilizando Node.js e Express.

## Como executar

Clone o repositório:

git clone https://github.com/seu-usuario/api-node-express.git

Entre na pasta do projeto:
cd api-node-express

Instale as dependências:
npm install

Inicie a aplicação:
node app.js

Se o servidor estiver configurado para a porta 3000, você poderá acessar:
http://localhost:3000
